# Banco de conectores — voz de Raquel

Paleta de conectores por función para redactar la memoria con fluidez y coherencia, en la voz de Raquel. Lo
leen `redactor-tesis` (al escribir) y `estilo-raquel` / `detector-ia` (al auditar). Complementa
`memoria/ESTILO_Y_ANTIIA.md` y las reglas de `memoria/correcciones_aprendidas.md`.

## Reglas de uso (obligatorias)

1. **Variedad obligatoria.** Ningún conector aparece dos veces seguidas en el mismo párrafo. Si hace falta
   «además» otra vez, la segunda usa «asimismo», «junto con» o «a esto se añade».
2. **Conexión implícita siempre que se pueda.** El orden lógico bien construido no necesita etiqueta.
   «El leverage effect implica correlación negativa entre retornos y volatilidad. STRATA explota esta asunción»
   —sin «por tanto» delante— es mejor que «…implica correlación negativa. Por tanto, STRATA explota…».
3. **Densidad razonable.** Mucho es relleno; poco puede ser saltos sin puente lógico. Conecta donde el lector lo
   necesita, no en cada frase.

## Prohibidos — reformular (no usar nunca)

Estos **anuncian la redacción** en vez de decir la idea: son tells de IA y violan la regla de meta-comentarios
de `correcciones_aprendidas.md` (prioridad alta). El énfasis se pone **dentro** de la frase, no anunciándolo.

| Prohibido (anuncia) | Reformulación (énfasis integrado) |
|---|---|
| conviene subrayar que X | esto subraya X · lo decisivo es X |
| cabe destacar que X | X destaca por… · lo central es X |
| cabe mencionar que X | (dilo directamente) X |
| es importante señalar que X | X es lo que importa · merece atención que X |
| es esencial que X | X es imprescindible para… |
| como veremos / como se verá | (no anuncies; enúncialo cuando toque) |
| insistimos en que / a lo largo de la memoria | (enúncialo una sola vez, sin anunciar la repetición) |
